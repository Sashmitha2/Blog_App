# Blog_App – CI/CD Practice

## Overview

This repository contains a sample Laravel application used to practice and test Continuous Integration and Continuous Deployment (CI/CD) workflows using GitHub Actions.

## Purpose

The main purpose of this project was to explore GitHub Actions and understand how automated workflows can be configured for a software project.

## Technologies

* Laravel
* PHP
* Git and GitHub
* GitHub Actions

## Project Status

This is a learning and CI/CD testing project, not a fully developed blog application.
